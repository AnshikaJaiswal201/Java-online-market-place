1. Executive Summary & Architecture

The ShopVerse Online Market Place System is an enterprise-grade multi-vendor e-commerce platform designed to connect Indian merchants (sellers) and buyers (customers) on a unified digital storefront. Built around native Indian product verticals—Electronics & Gadgets, Traditional Indian Wear & Banarasi Sarees, Spices & Gourmet Herbs, and Handicrafts & Home Decor—the platform operates as a modern 3-Tier Enterprise Application: an Angular 14 Single Page Application (SPA), a Java 17 and Spring Boot 3.2.5 RESTful API backend with Spring Security 6, and a local MySQL 8.0 database engine accessed via Spring Data JPA and Hibernate ORM.

An authenticated customer can search 24 pre-seeded Indian catalog products, filter items by category, manage persistent shopping carts, and execute atomic transactional checkouts with stock decrement guarantees. Merchants log into their dedicated Seller Central workspace to inspect real-time revenue metrics formatted in Indian Rupees (₹), track order volumes, monitor stock levels, update SKU inventories, and receive automated low-stock warnings when inventory drops below threshold limits.

2. Project Workflow & Architecture

2.1 Step-by-step operation

  1. User Registration & Database Save: A new user registers at /auth/register selecting either CUSTOMER or SELLER role. The Angular frontend dispatches a POST request to /api/auth/register. Spring Boot hashes the password using BCrypt with salt rounds = 10, associates the user with ROLE_CUSTOMER or ROLE_SELLER in the user_roles junction table, and commits the record to MySQL shopverse_db.users.
  2. User Authentication & JWT Issuance: The user signs in on /auth/login. Spring Security authenticates the credentials against MySQL database. Upon validation, the backend generates an HMAC-SHA256 JSON Web Token (JWT) with 24-hour expiration containing the user's ID, email, and authorities. Angular stores this token in browser LocalStorage.
  3. Catalog Discovery & Category Filtering: The customer explores 24 authentic Indian products across Electronics, Banarasi Sarees, Kashmiri Spices, and Handicrafts. Angular makes a GET request to /api/products, displaying live stock status, seller badges, and rupee pricing.
  4. Shopping Cart Management: Customers add items to their persistent shopping cart. The backend verifies real-time stock availability and recalculates dynamic subtotals. The Angular cart view provides quantity increment and decrement controls.
  5. ACID Transactional Checkout: When the customer confirms checkout, Spring Boot executes an atomic @Transactional service: stock quantities are deducted from the inventory table, an immutable order ORD-YYYYMMDD-XXXX is generated in the orders and order_items tables, and all cart items are flushed.
  6. Seller Analytics & Inventory Restocking: Merchants sign into Seller Central to inspect real-time gross revenue in INR (₹), fulfilled order counts, active listings, and inventory levels with automatic low-stock warnings when quantity <= 5.

2.2 System Architecture

The application follows a decoupled Three-Tier Enterprise Architecture: Presentation Layer (Angular 14 SPA), Application / Business Logic Layer (Java 17 + Spring Boot 3.2.5 RESTful API), and Data Persistence Layer (MySQL 8.0 Relational Database). Communication between the frontend and backend is handled strictly via stateless HTTP REST JSON endpoints secured with Bearer JWT Authorization headers.

3.1 Billing & Inventory Calculation Formulas

• Line Item Subtotal: Subtotal (₹) = Unit Price × Quantity

• Order Gross Total: Total Amount = Sum of (Line Item Subtotals) + Shipping Fee (₹0 for Orders >= ₹500)

• Atomic Stock Deduction: Remaining Stock = Current Stock Quantity - Order Line Quantity (WHERE Current Stock >= Order Line Quantity)

• Low-Stock Threshold Condition: Alert Triggered WHEN stock_quantity <= low_stock_threshold (default = 5)

    FOREIGN KEY (role_id) REFERENCES roles(role_id) ON DELETE CASCADE

    description VARCHAR(500),
    is_active TINYINT DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP

    product_id BIGINT AUTO_INCREMENT PRIMARY KEY,

import io.jsonwebtoken.*;
import io.jsonwebtoken.security.Keys;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.GrantedAuthority;
import org.springframework.stereotype.Component;

import java.nio.charset.StandardCharsets;
import java.security.Key;
import java.util.Date;
import java.util.List;
import java.util.stream.Collectors;

@Component
public class JwtTokenProvider {

    private static final Logger logger = LoggerFactory.getLogger(JwtTokenProvider.class);

    @Value("${app.jwt.secret}")
    private String jwtSecret;

    @Value("${app.jwt.expiration-ms}")
    private long jwtExpirationMs;

    private Key getSigningKey() {
        byte[] keyBytes = jwtSecret.getBytes(StandardCharsets.UTF_8);
        return Keys.hmacShaKeyFor(keyBytes);
    }

    public String generateToken(Authentication authentication) {
        CustomUserDetails userPrincipal = (CustomUserDetails) authentication.getPrincipal();

        List<String> roles = userPrincipal.getAuthorities().stream()
                .map(GrantedAuthority::getAuthority)
                .collect(Collectors.toList());

        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + jwtExpirationMs);

        return Jwts.builder()
                .setSubject(userPrincipal.getUsername())
                .claim("userId", userPrincipal.getUserId())
                .claim("fullName", userPrincipal.getFullName())
                .claim("roles", roles)
                .setIssuedAt(now)
                .setExpiration(expiryDate)
                .signWith(getSigningKey(), SignatureAlgorithm.HS256)
                .compact();
    }

    public String getEmailFromToken(String token) {
        Claims claims = Jwts.parserBuilder()
                .setSigningKey(getSigningKey())
                .build()
                .parseClaimsJws(token)
                .getBody();

        return claims.getSubject();
    }

    public boolean validateToken(String authToken) {
        try {
            Jwts.parserBuilder()
                    .setSigningKey(getSigningKey())
                    .build()
                    .parseClaimsJws(authToken);
            return true;
        } catch (SecurityException | MalformedJwtException e) {
            logger.error("Invalid JWT signature: {}", e.getMessage());
        } catch (ExpiredJwtException e) {
            logger.error("JWT token is expired: {}", e.getMessage());
        } catch (UnsupportedJwtException e) {
            logger.error("JWT token is unsupported: {}", e.getMessage());
        } catch (IllegalArgumentException e) {
            logger.error("JWT claims string is empty: {}", e.getMessage());
        }
        return false;
    }
}

import org.springframework.security.web.authentication.WebAuthenticationDetailsSource;
import org.springframework.stereotype.Component;
import org.springframework.util.StringUtils;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;

@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtTokenProvider tokenProvider;
    private final UserDetailsServiceImpl userDetailsService;

    public JwtAuthenticationFilter(JwtTokenProvider tokenProvider, UserDetailsServiceImpl userDetailsService) {
        this.tokenProvider = tokenProvider;
        this.userDetailsService = userDetailsService;
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain) throws ServletException, IOException {
        try {
            String jwt = parseJwt(request);
            if (StringUtils.hasText(jwt) && tokenProvider.validateToken(jwt)) {
                String email = tokenProvider.getEmailFromToken(jwt);
                UserDetails userDetails = userDetailsService.loadUserByUsername(email);

                UsernamePasswordAuthenticationToken authentication =
                        new UsernamePasswordAuthenticationToken(userDetails, null, userDetails.getAuthorities());
                authentication.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));

                SecurityContextHolder.getContext().setAuthentication(authentication);
            }
        } catch (Exception e) {
            logger.error("Cannot set user authentication: {}", e);
        }

        filterChain.doFilter(request, response);
    }

    private String parseJwt(HttpServletRequest request) {
        String headerAuth = request.getHeader("Authorization");
        if (StringUtils.hasText(headerAuth) && headerAuth.startsWith("Bearer ")) {
            return headerAuth.substring(7);
        }
        return null;
    }
}

    @Override
    public AuthResponse login(LoginRequest request) {
        String email = request.getEmail() != null ? request.getEmail().trim().toLowerCase() : "";
        Authentication authentication = authenticationManager.authenticate(
                new UsernamePasswordAuthenticationToken(email, request.getPassword())
        );

        SecurityContextHolder.getContext().setAuthentication(authentication);
        String jwt = tokenProvider.generateToken(authentication);

        CustomUserDetails userPrincipal = (CustomUserDetails) authentication.getPrincipal();
        List<String> roles = userPrincipal.getAuthorities().stream()
                .map(GrantedAuthority::getAuthority)
                .collect(Collectors.toList());

        return new AuthResponse(jwt, userPrincipal.getUserId(), userPrincipal.getUsername(),
                userPrincipal.getFullName(), roles);
    }

    @Override
    @Transactional
    public AuthResponse register(RegisterRequest request) {
        String email = request.getEmail() != null ? request.getEmail().trim().toLowerCase() : "";
        if (userRepository.existsByEmail(email)) {
            throw new BadRequestException("Error: Email is already registered: " + email);
        }

        User user = new User();
        user.setEmail(email);
        user.setPassword(passwordEncoder.encode(request.getPassword()));
        user.setFullName(request.getFullName() != null ? request.getFullName().trim() : "");
        user.setPhoneNumber(request.getPhoneNumber());
        user.setAddressLine1(request.getAddressLine1());
        user.setCity(request.getCity());
        user.setState(request.getState());
        user.setPinCode(request.getPinCode());
        user.setIsActive(1);

        String roleStr = request.getRole() != null ? request.getRole().trim().toUpperCase() : "CUSTOMER";
        String normalizedRoleName = roleStr.startsWith("ROLE_") ? roleStr : "ROLE_" + roleStr;

        if (!normalizedRoleName.equals(Constants.ROLE_CUSTOMER) && !normalizedRoleName.equals(Constants.ROLE_SELLER)) {
            throw new BadRequestException("Invalid role specified. Allowed values: CUSTOMER, SELLER");
        }

        Role userRole = roleRepository.findByRoleName(normalizedRoleName)
                .orElseGet(() -> roleRepository.save(new Role(normalizedRoleName, "Role for " + normalizedRoleName)));

        Set<Role> roles = new HashSet<>();
        roles.add(userRole);
        user.setRoles(roles);

        User savedUser = userRepository.save(user);

        // Authenticate new registered user
        Authentication authentication = authenticationManager.authenticate(
                new UsernamePasswordAuthenticationToken(email, request.getPassword())
        );

        SecurityContextHolder.getContext().setAuthentication(authentication);
        String jwt = tokenProvider.generateToken(authentication);

        List<String> roleNames = savedUser.getRoles().stream()
                .map(Role::getRoleName)
                .collect(Collectors.toList());

        return new AuthResponse(jwt, savedUser.getUserId(), savedUser.getEmail(), savedUser.getFullName(), roleNames);
    }

    }

    @Override
    @Transactional(isolation = Isolation.READ_COMMITTED, rollbackFor = Exception.class)
    public OrderResponse checkout(Long customerId, CheckoutRequest request) {
        User customer = userRepository.findById(customerId)
                .orElseThrow(() -> new ResourceNotFoundException("Customer", "id", customerId));

        List<CartItem> cartItems = cartItemRepository.findByUser_UserIdOrderByCreatedAtDesc(customerId);
        if (cartItems.isEmpty()) {
            throw new BadRequestException("Your cart is empty. Add products before checking out.");
        }

        // Build Order
        Order order = new Order();
        String dateStr = LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMdd"));
        int randomSuffix = ThreadLocalRandom.current().nextInt(1000, 9999);
        order.setOrderNumber("ORD-" + dateStr + "-" + randomSuffix);
        order.setCustomer(customer);
        order.setShippingAddress(request.getShippingAddress());
        order.setPaymentMethod(request.getPaymentMethod() != null ? request.getPaymentMethod() : "UPI");
        order.setPaymentStatus(Constants.PAYMENT_STATUS_PAID); // Mock checkout payment success
        order.setOrderStatus(Constants.ORDER_STATUS_PLACED);

        BigDecimal totalAmount = BigDecimal.ZERO;
        List<OrderItem> orderItems = new ArrayList<>();

        for (CartItem cartItem : cartItems) {
            Long productId = cartItem.getProduct().getProductId();
            int quantity = cartItem.getQuantity();

            // Atomic inventory deduction with rollback protection
            inventoryService.deductStock(productId, quantity);

            BigDecimal unitPrice = cartItem.getProduct().getPrice();
            BigDecimal subtotal = unitPrice.multiply(BigDecimal.valueOf(quantity));
            totalAmount = totalAmount.add(subtotal);

            OrderItem orderItem = new OrderItem(
                    order,
                    cartItem.getProduct(),
                    cartItem.getProduct().getSeller(),
                    quantity,
                    unitPrice,
                    subtotal
            );
            orderItems.add(orderItem);
        }

        order.setTotalAmount(totalAmount);
        order.setItems(orderItems);

        Order savedOrder = orderRepository.save(order);

        // Clear cart after successful checkout
        cartItemRepository.deleteByUser_UserId(customerId);

        return mapToOrderResponse(savedOrder);
    }

import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { BehaviorSubject, Observable, tap } from 'rxjs';
import { environment } from '../../../environments/environment';
import { ApiResponse, AuthResponse, User } from '../../shared/models/models';

@Injectable({
  providedIn: 'root'
})
export class AuthService {
  private apiUrl = `${environment.apiUrl}/auth`;
  private currentUserSubject = new BehaviorSubject<User | null>(null);
  public currentUser$ = this.currentUserSubject.asObservable();

  constructor(private http: HttpClient) {
    this.loadStoredUser();
  }

  private loadStoredUser(): void {
    const storedUser = localStorage.getItem('user_details');
    if (storedUser) {
      try {
        this.currentUserSubject.next(JSON.parse(storedUser));
      } catch (e) {
        this.logout();
      }
    }
  }

  login(credentials: { email: string; password: string }): Observable<ApiResponse<AuthResponse>> {
    return this.http.post<ApiResponse<AuthResponse>>(`${this.apiUrl}/login`, credentials).pipe(
      tap(res => {
        if (res.success && res.data) {
          this.setSession(res.data);
        }
      })
    );
  }

  register(userData: any): Observable<ApiResponse<AuthResponse>> {
    this.logout();
    return this.http.post<ApiResponse<AuthResponse>>(`${this.apiUrl}/register`, userData);
  }

  private setSession(authData: AuthResponse): void {
    localStorage.setItem('auth_token', authData.token);
    const user: User = {
      userId: authData.userId,
      email: authData.email,
      fullName: authData.fullName,
      roles: authData.roles
    };
    localStorage.setItem('user_details', JSON.stringify(user));
    this.currentUserSubject.next(user);
  }

  logout(): void {
    localStorage.removeItem('auth_token');
    localStorage.removeItem('user_details');
    this.currentUserSubject.next(null);
  }

  getToken(): string | null {
    return localStorage.getItem('auth_token');
  }

  isLoggedIn(): boolean {
    return !!this.getToken();
  }

  currentUserValue(): User | null {
    return this.currentUserSubject.value;
  }

  hasRole(role: string): boolean {
    const user = this.currentUserValue();
    if (!user || !user.roles) return false;
    const normalized = role.startsWith('ROLE_') ? role : `ROLE_${role}`;
    return user.roles.includes(normalized);
  }

  isCustomer(): boolean {
    return this.hasRole('ROLE_CUSTOMER');
  }

  isSeller(): boolean {
    return this.hasRole('ROLE_SELLER');
  }
}

@Injectable()
export class JwtInterceptor implements HttpInterceptor {
  constructor(private authService: AuthService) {}

  intercept(request: HttpRequest<unknown>, next: HttpHandler): Observable<HttpEvent<unknown>> {
    const token = this.authService.getToken();
    if (token) {
      request = request.clone({

        }
      });
    }
    return next.handle(request);
  }

    private fb: FormBuilder,
    private authService: AuthService,
    private router: Router,
    private route: ActivatedRoute

      email: ['', [Validators.required, Validators.email]],

import { Component, OnInit } from '@angular/core';
import { Router } from '@angular/router';
import { CartService } from '../../../core/services/cart.service';
import { CartItem, CartSummary } from '../../../shared/models/models';

@Component({
  selector: 'app-cart-view',
  templateUrl: './cart-view.component.html',
  styleUrls: ['./cart-view.component.css']
})
export class CartViewComponent implements OnInit {
  cart: CartSummary | null = null;
  loading = false;
  errorMessage = '';

  constructor(
    private cartService: CartService,
    private router: Router
  ) {}

  ngOnInit(): void {
    this.fetchCart();
  }

  fetchCart(): void {
    this.loading = true;
    this.cartService.loadCart().subscribe({
      next: (res) => {
        this.loading = false;
        if (res.success) {
          this.cart = res.data;
        }
      },
      error: (err) => {
        this.loading = false;
        this.errorMessage = err.message || 'Failed to load shopping cart';
      }
    });
  }

  increaseQuantity(item: CartItem): void {
    if (item.quantity >= item.availableStock) {
      alert(`Cannot exceed available stock of ${item.availableStock} units`);
      return;
    }
    this.cartService.updateQuantity(item.cartItemId, item.quantity + 1).subscribe({
      next: (res) => {
        if (res.success) {
          this.cart = res.data;
        }
      },
      error: (err) => alert(err.message)
    });
  }

  decreaseQuantity(item: CartItem): void {
    if (item.quantity <= 1) {
      this.removeItem(item);
      return;
    }
    this.cartService.updateQuantity(item.cartItemId, item.quantity - 1).subscribe({
      next: (res) => {
        if (res.success) {
          this.cart = res.data;
        }
      },
      error: (err) => alert(err.message)
    });
  }

  removeItem(item: CartItem): void {
    if (confirm(`Remove "${item.productName}" from your cart?`)) {
      this.cartService.removeFromCart(item.cartItemId).subscribe({
        next: (res) => {
          if (res.success) {
            this.cart = res.data;
          }
        },
        error: (err) => alert(err.message)
      });
    }
  }

  clearCart(): void {
    if (confirm('Are you sure you want to empty your entire cart?')) {
      this.cartService.clearCart().subscribe({
        next: () => {
          this.cart = null;
        },
        error: (err) => alert(err.message)
      });
    }
  }

  proceedToCheckout(): void {
    this.router.navigate(['/checkout']);
  }
}

import { Component, OnInit } from '@angular/core';
import { FormBuilder, FormGroup, Validators } from '@angular/forms';
import { SellerService } from '../../../core/services/seller.service';
import { InventoryItem } from '../../../shared/models/models';

@Component({
  selector: 'app-seller-inventory',
  templateUrl: './seller-inventory.component.html',
  styleUrls: ['./seller-inventory.component.css']
})
export class SellerInventoryComponent implements OnInit {
  inventory: InventoryItem[] = [];
  loading = false;
  selectedItem: InventoryItem | null = null;
  stockForm: FormGroup;
  showModal = false;
  successMessage = '';
  errorMessage = '';

  constructor(
    private sellerService: SellerService,
    private fb: FormBuilder
  ) {
    this.stockForm = this.fb.group({
      stockQuantity: ['', [Validators.required, Validators.min(0)]],
      lowStockThreshold: ['', [Validators.required, Validators.min(1)]]
    });
  }

  ngOnInit(): void {
    this.fetchInventory();
  }

  fetchInventory(): void {
    this.loading = true;
    this.sellerService.getInventory().subscribe({
      next: (res) => {
        this.loading = false;
        if (res.success) {
          this.inventory = res.data;
        }
      },
      error: (err) => {
        this.loading = false;
        this.errorMessage = err.message || 'Failed to load inventory';
      }
    });
  }

  openRestockModal(item: InventoryItem): void {
    this.selectedItem = item;
    this.stockForm.patchValue({
      stockQuantity: item.stockQuantity,
      lowStockThreshold: item.lowStockThreshold
    });
    this.showModal = true;
  }

  closeModal(): void {
    this.showModal = false;
    this.selectedItem = null;
  }

  onSubmit(): void {
    if (this.stockForm.invalid || !this.selectedItem) {
      return;
    }

    const { stockQuantity, lowStockThreshold } = this.stockForm.value;

    this.sellerService.updateStock(this.selectedItem.inventoryId, stockQuantity, lowStockThreshold).subscribe({
      next: (res) => {
        if (res.success) {
          this.closeModal();
          this.fetchInventory();
          this.successMessage = `Inventory updated for "${res.data.productName}"`;
          setTimeout(() => this.successMessage = '', 3000);
        }
      },
      error: (err) => alert(err.message)
    });
  }
}

8. Conclusion & Future Scope

The ShopVerse Online Market Place System successfully demonstrates an end-to-end multi-vendor e-commerce application engineered with production standards. All layers of the Three-Tier Architecture have been implemented, integrated, and validated: an Angular 14 reactive client SPA, a robust Java 17 and Spring Boot 3.2.5 REST backend with Spring Security 6 stateless JWT authentication, and a normalized MySQL 8.0 relational database engine with ACID transactional order processing.

The output screenshots confirm that user registration saves credentials into MySQL, login issues valid JWT tokens, the product catalog showcases authentic Indian merchandise with live stock counts, and the seller dashboard accurately computes metrics in Indian Rupees (₹).

Key future scope enhancements:

  1. Payment Gateway Integration: Integrate production payment webhooks using Razorpay and Stripe SDKs for automated UPI, credit card, and net banking reconciliation.
  2. Automated PDF GST Invoicing: Implement Spring Boot reporting services with iText or JasperReports to automatically generate downloadable GST tax invoice PDFs upon order completion.
  3. SMS and Email Notifications: Implement asynchronous messaging via Spring Boot Mail and Twilio APIs to dispatch dispatch notifications and delivery OTPs.
  4. Full-Text Search with Elasticsearch: Introduce an Elasticsearch cluster alongside MySQL to provide fuzzy keyword matching, typo-tolerance, and instant faceted search across massive catalogs.
